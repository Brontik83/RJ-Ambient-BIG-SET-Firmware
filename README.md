# RJ Ambient BIG SET – firmware

Veřejná distribuce podepsaných aktualizací BIG SET.

Aktuální vydání: **V1.2.6**. Podepsaný BIN je v [Releases](https://github.com/Brontik83/RJ-Ambient-BIG-SET-Firmware/releases/latest) a ve složce `firmware/` pro dvoufázovou aktualizaci přes telefon. `manifest.json` je zveřejněn po ověření vydání.

Profil: `RJ_AMBIENT_IVECO_28LED_HW1`. Určeno pro **BIG SET (IVECO, koník, miska a řídicí jednotka raků)**. Nepoužívat pro původní samostatný nápis IVECO. Klíč a profil zůstaly kompatibilní; zkontrolujte variantu zařízení před ručním uploadem.

V1.2.6 přidává samostatný aktualizační kanál BIG SET; obsahuje přehled, jednotlivé a společné vypínače a volbu chování D5. Aktualizace se instalují na povel uživatele.

Ověřeno sestavení ESP8266 Core 3.1.2 / NeoPixelBus 2.8.4 a digitální podpis. Na fyzickém zařízení dosud neotestováno.

Zdrojové kódy jsou v soukromém repozitáři. Soukromé podpisové klíče nejsou součástí veřejné distribuce.
